# SI Tutor

โปรเจกต์ตั้งต้นสำหรับเว็บเรียนออนไลน์ ใช้ Next.js App Router, React, TypeScript และ Tailwind CSS

## เริ่มใช้งาน

ต้องมี Node.js 20.9 ขึ้นไปและ npm

```powershell
npm install
npm run dev
```

เปิดหน้าเว็บที่ http://localhost:3000 โค้ดหน้าเว็บอยู่ใน `src/app`

## ตรวจโปรเจกต์

```powershell
npm run lint
npm run build
npm run typecheck
```
